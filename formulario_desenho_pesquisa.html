1

Identificação do Protocolo

Informações básicas que identificam a revisão e sua equipe.

📖 Cochrane (2019), Cap. 1: O protocolo de revisão sistemática deve ser registrado previamente para garantir transparência e evitar duplicação de esforços. Registre-o no PROSPERO quando possível.
Deve conter a estrutura PICO. Ex.: "Efeitos de [Intervenção] em [Desfecho] para [População]: Uma Revisão Sistemática"
Adicione os nomes dos co-revisores. Mínimo recomendado: 2 revisores para a triagem (Cochrane, 2019).
Se já registrado. Ex.: CRD42024000000
2

Questão de Pesquisa

Defina a pergunta central usando um framework estruturado.

📖 Cochrane (2019), Cap. 2: A pergunta deve ser clara, focada e formulável dentro de um framework (PICO, PICo, SPIDER, PEO). Para revisões de intervenção, use PICO. Para revisões qualitativas/exploratórias, use PICo ou SPIDER.

P — População / Problema

Quem são os participantes ou qual é o contexto do problema?

I — Interesse / Intervenção

Qual fenômeno de interesse, intervenção ou exposição?

Co — Contexto / Comparação

Qual o contexto ou comparador?

O — Resultado (Outcome)

Quais desfechos ou resultados são avaliados?

3

Critérios de Elegibilidade

Defina os critérios de inclusão e exclusão a priori.

📖 Campbell (2020): Os critérios devem ser definidos antes da busca para evitar viés de seleção. Documente explicitamente os tipos de estudo, participantes, intervenção/exposição e desfechos aceitáveis.
Condições que um estudo DEVE atender para ser incluído.
Condições que EXCLUEM um estudo mesmo que atenda os critérios acima.
4

Estratégia de Busca

Monte a expressão booleana e defina os termos para alimentar os coletores.

📖 Cochrane (2019), Cap. 4: A estratégia de busca deve ser altamente sensível. Use termos livres, descritores controlados (MeSH/DeCS) e sinônimos. Combine blocos conceituais com operadores booleanos (AND, OR, NOT).
Prévia da expressão booleana
Configure os blocos acima para gerar a expressão...
Define em quais campos da Scopus a busca será aplicada.
5

Fontes de Dados

Selecione as bases de dados a serem consultadas pelos coletores.

📖 Cochrane (2019), Cap. 4.3: No mínimo MEDLINE e Cochrane Library. Campbell (2020) recomenda pelo menos 3 bases relevantes à área. As bases escolhidas determinam os configs que serão gerados.
Bases que serão buscadas fora do software (importação manual de registros).
Obtenha em dev.elsevier.com. Deixe em branco para usar a chave do config atual.
Garante limites ampliados de requisição. Ex.: user@mail.com
6

Triagem e Seleção

Defina o processo de screening por título/resumo e texto completo.

📖 Cochrane (2019), Cap. 4.6: A triagem deve ser feita em duas fases: (1) título e resumo, (2) texto completo. Pelo menos dois revisores independentes devem participar para reduzir viés. Conflitos devem ser resolvidos por consenso ou um terceiro revisor.
Escolha o software auxiliar para organizar a triagem (ou use as planilhas geradas).
Cochrane recomenda calibrar os critérios com um lote-piloto antes da triagem completa.
7

Extração de Dados

Defina as variáveis a serem extraídas dos estudos incluídos.

📖 Cochrane (2019), Cap. 5: Use formulários padronizados de extração. Extraia dados bibliográficos, características do estudo, detalhes da intervenção, desfechos e resultados numéricos. Faça extração dupla para minimizar erros.
Selecione os campos que devem compor a planilha de extração de dados. Campos coletados automaticamente pelo software estão marcados como (Auto).
8

Avaliação da Qualidade Metodológica

Defina o instrumento de avaliação de risco de viés.

📖 Cochrane (2019), Cap. 8: Use ferramentas validadas de avaliação de viés. A ferramenta ROB 2 é padrão para ECRs; ROBINS-I para estudos não randomizados. Para revisões de escopo, considere MMAT ou checklists JBI.
Defina os níveis de classificação que aparecerão na planilha.
9

Síntese dos Resultados

Planeje a estratégia de síntese e o tipo de análise.

📖 Cochrane (2019), Cap. 10-12: A meta-análise é viável quando os estudos são homogêneos o suficiente. Caso contrário, opte por síntese narrativa estruturada. Avalie a heterogeneidade (I²) e planeje análises de sensibilidade.
Análises de subgrupo, análise de sensibilidade, funnel plot, etc.
